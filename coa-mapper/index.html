    Integration commentary

    Claude drafts a short note from the figures above. It reads the computed KPIs only, not the raw ledger.
    How it works
    Rules first

    A keyword rule set maps each account in code, so the page works without Claude. Accounts whose line depends on policy (warehouse labor, freight-out, owner pay, recall costs) are marked.

    Claude checks

    Claude maps the same accounts independently. Where it disagrees with the rules, the row is highlighted with both answers; the rules' answer stays until you choose.

    You decide

    Every dropdown is yours. Add-backs mapped to 7200 are candidates for the QoE, never accepted adjustments.

    Numbers from code

    Roll-ups, margins, gaps and exceptions are arithmetic on the mapped rows. Claude only drafts words around them.
